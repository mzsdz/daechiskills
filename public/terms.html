한 게시물에는 한 문제

문제 이미지 한 장을 선택하고 필요한 영역만 잘라 올립니다. 여러 문제가 담겼는지는 사용자가 확인합니다. AI 인식은 문제 한 개 여부 확인을 보조하며, 최종 등록 전에 작성자가 확인합니다.

내 것과 공개할 수 있는 것

문제는 기본 비공개입니다. 직접 만든 문제 또는 공개 게시 허락을 받은 문제만 광장에 올리세요. 출처 태그는 작성자가 입력하며, 확인된 출처라는 인증을 뜻하지 않습니다.

공개 범위

문제와 손풀이는 각각 공개 범위를 갖습니다. 비공개 콘텐츠와 이미지는 작성자만 볼 수 있습니다. 문제를 비공개로 바꾸면 다른 사람의 공개 손풀이도 광장에서 숨겨집니다. 각 작성자는 자신의 손풀이를 계속 보유합니다.

아카이브 공개는 다른 사람이 내 공개 손풀이 목록을 방문할 수 있게 합니다. 추앙은 자동 수락 또는 확인 후 수락으로 설정하며, 승인 대기는 추앙 숫자에 포함되지 않습니다. 추앙 수락만으로 비공개 손풀이가 공개되지는 않습니다. 비공개 손풀이나 수집함은 공개되지 않습니다. 아카이브만 비공개로 해도 이미 공개한 손풀이는 원래 문제에서 볼 수 있습니다. 손풀이까지 숨기려면 해당 풀이도 비공개로 바꾸세요.

삭제와 신고

문제 원문 삭제 시 원문 내용과 이미지를 제거하고 참조 자리는 남깁니다. 다른 사람이 쓴 손풀이는 독립된 콘텐츠로 유지됩니다. 자신의 손풀이는 직접 삭제할 수 있습니다. 저작권·개인정보·부적절한 내용은 문제 또는 풀이의 신고 버튼으로 접수하세요. 신고가 접수돼도 자동 삭제되지는 않으며 운영자가 검토합니다.

계정과 정보

이메일은 인증에 사용하며 공개 프로필에 노출하지 않습니다. 활동 이름·소개·공개 활동은 다른 사람이 볼 수 있습니다. 개인정보가 담긴 사진을 올리지 마세요. 인증 세션은 로그인 유지를 위해 이 브라우저에 저장됩니다.

포인트

가입 후 첫 로그인 시 가입 축하 5,000P를 계정당 한 번 지급합니다. 기존 베타 회원에게도 같은 혜택을 지급합니다. 잔액과 내역은 본인만 확인할 수 있습니다. 현재 포인트 충전·양도·현금 환전·풀이팩 구매는 제공하지 않습니다. AI 문제 인식은 일반 회원 하루 10회 무료이며 관리자는 무제한입니다. 사용량은 한국 시간 자정에 초기화됩니다. 인식 실패는 사용량에 포함하지 않으며 오류 반복을 막기 위한 재시도 한도는 별도로 적용됩니다. 선택한 이미지는 인식을 위해 OpenAI로 전송됩니다. AI가 채운 본문·분류·출처는 등록 전에 확인해 주세요. 출처 표기는 원문 대조 인증이 아닙니다.

공개 등록 보상

공개 권한을 확인한 본문 20자 이상의 문제를 광장에 등록하면 100P를 지급합니다. 계정당 하루 10건, 최대 1,000P이며 관리자도 보상 한도는 같습니다. 동일 본문의 중복 등록과 같은 게시물 재공개에는 다시 지급하지 않습니다. 비공개 저장·이미지만 있는 직접 등록은 보상 대상이 아닙니다. 보상 이력은 문제 삭제 후에도 유지되어 재등록으로 다시 받을 수 없습니다. 문맥이 같은 변형 문제까지 자동 판별하는 기능은 아직 없습니다.

베타의 범위

2015 기출 범위의 전 과목 조각 개념 1차 도감을 제공합니다. 기출 연결은 본문 단서 또는 단원 분류로 만든 검토 전 후보이며 관리자 확인 여부를 표시합니다. 개념 내용도 최종 검수 전인 경우 1차 도감으로 표시합니다. 개념 수집과 오류 제보를 제공하며 AI 자동 개념 추론과 풀이팩 판매는 아직 제공하지 않습니다.
